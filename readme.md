# VolumeBoostYT

This repository restores the original **candyzp/VolumeBoostYT** tweak that was previously available at `https://github.com/candyzp/VolumeBoostYT`.

Independent volume booster for the YouTube app on iOS.

Boosts the internal YouTube volume (up to 20× / 2000%) without changing the system volume. Controlled by a right-edge gesture with an on-screen HUD.

## Features

- Independent volume boost for YouTube (up to 2000% / 20×) without affecting system volume
- Right-edge swipe + drag gesture control
- On-screen percentage HUD
- Compatible with sideloaded YouTube (LiveContainer, TrollStore, etc.)
- Rootless package support
